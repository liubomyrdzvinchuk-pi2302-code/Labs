Робота 6. CSS: Flexbox

Гнучкі контейнери: напрям, вирівнювання, перенесення.

Завдання 1. Горизонтальне меню

Зробіть навігаційне меню з рівномірними відступами через flex.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.menu{display:flex;justify-content:space-between;background:#222;padding:10px 20px}
.menu a{color:#fff;text-decoration:none}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<nav class="menu"><a href="#">Головна</a><a href="#">Про нас</a><a href="#">Контакти</a></nav>
</body>
</html>

Результат

Завдання 2. Центрування

Відцентруйте блок по горизонталі та вертикалі.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.wrap{display:flex;justify-content:center;align-items:center;height:160px;background:#eef}
.c{background:#2a5bd7;color:#fff;padding:20px}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="wrap"><div class="c">Центр</div></div>
</body>
</html>

Результат

Завдання 3. Картки з переносом

Розмістіть 6 карток, що переносяться на новий рядок (flex-wrap) та розтягуються (flex-grow).

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.row{display:flex;flex-wrap:wrap;gap:10px}
.row div{flex:1 1 120px;background:#cfe3ff;padding:20px;text-align:center}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="row"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div></div>
</body>
</html>
