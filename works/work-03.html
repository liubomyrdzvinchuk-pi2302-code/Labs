Робота 3. HTML: форми

Завдання 1. Форма реєстрації

Створіть форму з іменем, email, паролем та кнопкою відправки (required).

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<form onsubmit="event.preventDefault();alert('Відправлено')">
  <p><label>Ім’я: <input type="text" name="name" required></label></p>
  <p><label>Email: <input type="email" name="email" required></label></p>
  <p><label>Пароль: <input type="password" minlength="6" required></label></p>
  <button type="submit">Зареєструватись</button>
</form>
</body>
</html>

Завдання 3. Різні типи input

Використайте типи date, range, color, number та textarea.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<form>
<p><input type="date"> <input type="number" min="1" max="10" value="5"></p>
<p><input type="range" min="0" max="100"> <input type="color" value="#ff8800"></p>
<p><textarea rows="3" cols="30" placeholder="Коментар"></textarea></p>
</form>
</body>
</html>
