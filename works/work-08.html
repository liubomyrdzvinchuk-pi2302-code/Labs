Робота 8. Адаптивний дизайн

Завдання 1. Відносні одиниці

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.a{width:80%;font-size:1.5rem;padding:1em;background:#eef;margin:auto}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="a">Ширина 80%, шрифт 1.5rem</div>
</body>
</html>

Завдання 2. Media query

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.m{padding:30px;background:#cfe3ff}
@media (max-width:500px){.m{background:#ffd6d6;font-size:14px}}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="m">Зменшіть вікно, щоб побачити зміну</div>
</body>
</html>

Завдання 3. Адаптивне меню

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.n{display:flex;gap:12px}
.n a{padding:8px 14px;background:#222;color:#fff;text-decoration:none}
@media (max-width:500px){.n{flex-direction:column}}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<nav class="n"><a href="#">Дім</a><a href="#">Новини</a><a href="#">Про нас</a></nav>
</body>
</html>
