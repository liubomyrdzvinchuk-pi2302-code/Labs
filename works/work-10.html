Робота 10. JavaScript: змінні, умови, функції

Типи даних, розгалуження, цикли, функції.

Завдання 1. Змінні та вивід

Оголосіть змінні різних типів і виведіть їх на сторінку.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<pre id="o"></pre>
<script>
const name='Іван';
let age=19;
const ok=true;
document.getElementById('o').textContent=
  `Ім'я: ${name}\nВік: ${age}\nСтудент: ${ok}\nТип віку: ${typeof age}`;
</script>
</body>
</html>

Результат

Завдання 2. Парне чи непарне

Напишіть функцію, що визначає парність числа, і перевірте її для чисел 1–6.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<pre id="o"></pre>
<script>
function parity(n){ return n % 2 === 0 ? 'парне' : 'непарне'; }
let out='';
for(let i=1;i<=6;i++) out+=i+' — '+parity(i)+'\n';
document.getElementById('o').textContent=out;
</script>
</body>
</html>

Результат

Завдання 3. Факторіал і Фібоначчі

Реалізуйте факторіал (рекурсія) та перші 10 чисел Фібоначчі (цикл).

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<pre id="o"></pre>
<script>
const fact=n=>n<=1?1:n*fact(n-1);
const fib=[0,1];
for(let i=2;i<10;i++) fib.push(fib[i-1]+fib[i-2]);
document.getElementById('o').textContent='5! = '+fact(5)+'\nFib: '+fib.join(', ');
</script>
</body>
</html>
