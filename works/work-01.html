Завдання 1. Візитка

Створіть сторінку-візитку із заголовком h1, підзаголовком h2 та двома абзацами про себе.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<h1>Іван Петренко</h1>
<h2>Студент, веб-розробник</h2>
<p>Мене звати <b>Іван</b>, навчаюся на 2 курсі.</p>
<p>Цікавлюся <i>HTML, CSS та JavaScript</i>.</p>
</body>
</html>

Завдання 2. Семантична розмітка

Розбийте сторінку на header, nav, main, section та footer.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<header><h1>Мій блог</h1></header>
<nav><a href="#a">Про мене</a> | <a href="#b">Статті</a></nav>
<main>
  <section id="a"><h2>Про мене</h2><p>Пишу про веб.</p></section>
  <section id="b"><h2>Статті</h2><p>Скоро з’являться.</p></section>
</main>
<footer><small>© 2026</small></footer>
</body>
</html>

Результат

Завдання 3. Посилання та якорі

Зробіть зміст із якірними посиланнями на розділи та зовнішнє посилання, що відкривається в новій вкладці.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<ul>
  <li><a href="#s1">Розділ 1</a></li>
  <li><a href="#s2">Розділ 2</a></li>
</ul>
<h2 id="s1">Розділ 1</h2><p>Текст першого розділу.</p>
<h2 id="s2">Розділ 2</h2><p>Текст другого розділу.</p>
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">MDN Web Docs</a>
</body>
</html>
