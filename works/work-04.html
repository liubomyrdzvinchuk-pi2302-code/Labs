Робота 4. CSS: селектори, кольори, текст

Підключення стилів, типи селекторів та оформлення тексту.

Завдання 1. Селектори

Стилізуйте елемент, клас та id різними кольорами.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
h2{color:#2a5bd7}
.note{color:green;font-style:italic}
#main{color:crimson;font-weight:bold}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<h2>Заголовок</h2>
<p class="note">Клас note</p>
<p id="main">Елемент з id</p>
</body>
</html>

Результат

Завдання 2. Типографіка

Налаштуйте шрифт, інтервали, вирівнювання та підкреслення тексту.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.t{font:20px/1.6 Georgia,serif;letter-spacing:1px;text-align:center;text-decoration:underline wavy #e91e63;text-transform:capitalize}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<p class="t">Красива типографіка робить текст читабельним.</p>
</body>
</html>

Результат

Завдання 3. Псевдокласи

Створіть посилання зі зміною вигляду при наведенні та список із різними кольорами рядків.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.btn{padding:8px 16px;background:#333;color:#fff;text-decoration:none;border-radius:6px}
.btn:hover{background:#e91e63}
li:nth-child(odd){background:#eef}
li:first-child{font-weight:bold}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<a href="#" class="btn">Наведи мене</a>
<ul><li>1</li><li>2</li><li>3</li><li>4</li></ul>
</body>
</html>
