Завдання 1. Зміна тексту і стилю

Змініть текст і колір заголовка за допомогою JS.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<h2 id="t">Старий заголовок</h2>
<script>
const t=document.getElementById('t');
t.textContent='Новий заголовок';
t.style.color='crimson';
t.classList.add('done');
</script>
</body>
</html>

Завдання 2. Створення елементів

Згенеруйте список з 5 пунктів у циклі.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<ul id="l"></ul>
<script>
const ul=document.getElementById('l');
for(let i=1;i<=5;i++){
  const li=document.createElement('li');
  li.textContent='Пункт '+i;
  ul.appendChild(li);
}
</script>
</body>
</html>

Завдання 3. Таблиця множення

Побудуйте таблицю множення 5×5 динамічно.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<table id="t" border="1" cellpadding="6"></table>
<script>
const t=document.getElementById('t');
for(let i=1;i<=5;i++){
  const r=t.insertRow();
  for(let j=1;j<=5;j++) r.insertCell().textContent=i*j;
}
</script>
</body>
</html>
