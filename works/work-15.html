Робота 15. Підсумковий міні-проєкт

Список справ, калькулятор і галерея — усе разом.

Завдання 1. Список справ (To-Do)

Додавайте, відмічайте та видаляйте завдання.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
li.done span{text-decoration:line-through;color:#888}
li{margin:6px 0}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<input id="i" placeholder="Нове завдання"> <button id="a">Додати</button>
<ul id="l"></ul>
<script>
a.onclick=()=>{
  if(!i.value.trim()) return;
  const li=document.createElement('li');
  li.innerHTML='<input type="checkbox"> <span></span> <button>✕</button>';
  li.querySelector('span').textContent=i.value;
  li.querySelector('input').onchange=e=>li.classList.toggle('done',e.target.checked);
  li.querySelector('button').onclick=()=>li.remove();
  l.appendChild(li); i.value='';
};
</script>
</body>
</html>

Завдання 2. Калькулятор

Реалізуйте калькулятор з чотирма діями.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<input id="x" type="number" value="8"> <select id="op"><option>+</option><option>−</option><option>×</option><option>÷</option></select> <input id="y" type="number" value="2"> <button id="eq">=</button> <b id="r"></b>
<script>
eq.onclick=()=>{
  const a=+x.value,b=+y.value;
  const f={'+':a+b,'−':a-b,'×':a*b,'÷':b?a/b:'ділення на 0'};
  r.textContent=f[op.value];
};
</script>
</body>
</html>

Завдання 3. Галерея з фільтром

Відфільтруйте кольорові плитки за категорією.

Код

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.g{display:flex;gap:8px;margin-top:10px}
.g div{width:60px;height:60px;border-radius:8px}
.red{background:#e53935}.blue{background:#1e88e5}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<button data-c="all">Усі</button> <button data-c="red">Червоні</button> <button data-c="blue">Сині</button>
<div class="g"><div class="red"></div><div class="blue"></div><div class="red"></div><div class="blue"></div></div>
<script>
document.querySelectorAll('button').forEach(b=>b.onclick=()=>{
  document.querySelectorAll('.g div').forEach(d=>
    d.style.display=(b.dataset.c==='all'||d.classList.contains(b.dataset.c))?'':'none');
});
</script>
</body>
</html>
