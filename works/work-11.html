Робота 11. JavaScript: масиви та об’єкти

Методи масивів, об’єкти, деструктуризація.

Завдання 1. Методи масиву

Із масиву чисел знайдіть квадрати, парні та суму (map, filter, reduce).

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<pre id="o"></pre>
<script>
const a=[1,2,3,4,5,6];
const sq=a.map(x=>x*x);
const ev=a.filter(x=>x%2===0);
const sum=a.reduce((s,x)=>s+x,0);
document.getElementById('o').textContent=
 `Квадрати: ${sq}\nПарні: ${ev}\nСума: ${sum}`;
</script>
</body>
</html>

Результат

Завдання 2. Масив об’єктів

Є список студентів. Відсортуйте за балом та виведіть середній бал.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<pre id="o"></pre>
<script>
const st=[{n:'Оля',s:88},{n:'Іван',s:75},{n:'Марія',s:95}];
st.sort((a,b)=>b.s-a.s);
const avg=st.reduce((s,x)=>s+x.s,0)/st.length;
document.getElementById('o').textContent=
 st.map(x=>x.n+': '+x.s).join('\n')+'\nСередній: '+avg.toFixed(1);
</script>
</body>
</html>

Результат

Завдання 3. Деструктуризація і spread

Скопіюйте та об’єднайте об’єкти, використавши деструктуризацію.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<pre id="o"></pre>
<script>
const user={name:'Ася',age:20};
const extra={city:'Київ'};
const full={...user,...extra,age:21};
const {name,city}=full;
document.getElementById('o').textContent=JSON.stringify(full)+'\n'+name+' з '+city;
</script>
</body>
</html>
