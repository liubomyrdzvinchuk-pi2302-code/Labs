Робота 5. CSS: блокова модель та позиціонування

margin, padding, border, display, position.

Завдання 1. Блокова модель

Створіть блок з padding, border та margin; використайте box-sizing.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.box{box-sizing:border-box;width:200px;height:100px;padding:15px;border:4px solid #2a5bd7;margin:20px auto;background:#e8efff}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="box">Блок 200×100</div>
</body>
</html>

Результат

Завдання 2. Display

Покажіть різницю між block, inline та inline-block.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.i{background:#fdd}
.ib{display:inline-block;width:120px;background:#dfd;padding:6px}
.b{background:#ddf;margin-top:6px}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<span class="i">inline</span><span class="i">inline</span>
<div class="ib">inline-block</div><div class="ib">inline-block</div>
<div class="b">block</div>
</body>
</html>

Результат

Завдання 3. Позиціонування

Розмістіть бейдж у куті картки через position: relative/absolute та закріпіть кнопку fixed.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.card{position:relative;width:200px;height:100px;border:1px solid #999;padding:12px}
.badge{position:absolute;top:-10px;right:-10px;background:red;color:#fff;padding:3px 8px;border-radius:12px;font-size:12px}
body{font-family:Arial,sans-serif;padding:12px};body{padding:30px}
</style>
</head>
<body>
<div class="card">Картка<span class="badge">NEW</span></div>
</body>
</html>
