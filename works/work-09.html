Робота 9. CSS: transition та animation

Плавні переходи, трансформації, keyframes.

Завдання 1. Transition

Зробіть кнопку, що плавно змінює колір та збільшується при наведенні.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.b{padding:12px 24px;border:0;border-radius:8px;background:#2a5bd7;color:#fff;transition:.3s}
.b:hover{background:#e91e63;transform:scale(1.15)}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<button class="b">Наведи</button>
</body>
</html>

Завдання 2. Keyframes

Створіть анімацію пульсації кола.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.p{width:60px;height:60px;border-radius:50%;background:#2a5bd7;margin:30px;animation:pulse 1.2s infinite}
@keyframes pulse{0%,100%{transform:scale(1);opacity:1}50%{transform:scale(1.5);opacity:.5}}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="p"></div>
</body>
</html>

Завдання 3. Обертання картки

Реалізуйте 3D-перевертання картки при наведенні.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.f{width:140px;height:90px;perspective:600px;margin:20px}
.in{position:relative;width:100%;height:100%;transition:.6s;transform-style:preserve-3d}
.f:hover .in{transform:rotateY(180deg)}
.fr,.bk{position:absolute;inset:0;display:grid;place-items:center;backface-visibility:hidden;color:#fff;border-radius:8px}
.fr{background:#2a5bd7}.bk{background:#e91e63;transform:rotateY(180deg)}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="f"><div class="in"><div class="fr">Перед</div><div class="bk">Зад</div></div></div>
</body>
</html>
