Робота 7. CSS: Grid

Двовимірні сітки: колонки, області, відступи.

Завдання 1. Сітка 3×2

Створіть сітку з трьох колонок та шести комірок.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.g{display:grid;grid-template-columns:repeat(3,1fr);gap:8px}
.g div{background:#cfe3ff;padding:20px;text-align:center}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="g"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div></div>
</body>
</html>

Результат

Завдання 2. Макет сторінки

Побудуйте макет header / sidebar / content / footer через grid-template-areas.

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.l{display:grid;grid-template-columns:120px 1fr;grid-template-areas:"h h" "s m" "f f";gap:6px}
header{grid-area:h;background:#fcd}aside{grid-area:s;background:#cdf}main{grid-area:m;background:#dfc;min-height:80px}footer{grid-area:f;background:#fec}
.l>*{padding:12px}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="l"><header>Header</header><aside>Sidebar</aside><main>Content</main><footer>Footer</footer></div>
</body>
</html>

Результат

Завдання 3. Адаптивна галерея

Зробіть галерею, що сама підбирає кількість колонок (auto-fit, minmax).

Код розв’язку

<!DOCTYPE html>
<html lang="uk">
<head>
<meta charset="UTF-8">
<title>Завдання</title>
<style>
.gal{display:grid;grid-template-columns:repeat(auto-fit,minmax(110px,1fr));gap:8px}
.gal div{height:80px;background:linear-gradient(135deg,#6a11cb,#2575fc);border-radius:8px}
body{font-family:Arial,sans-serif;padding:12px}
</style>
</head>
<body>
<div class="gal"><div></div><div></div><div></div><div></div><div></div><div></div></div>
</body>
</html>
